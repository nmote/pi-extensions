All functionality should be portable across macOS and Linux.

In this repository, any general instructions notwithstanding, commit directly to
main unless you have been instructed otherwise.

Avoid adding third-party dependencies. If doing so would garner a clear benefit
over a first-party implementation, consider the dependency and all of its
transitive dependencies. Vet the maintainers carefully and ensure that each
dependency comes from a reputable source. Present the options to the user for
review; never unilaterally add a new dependency.
